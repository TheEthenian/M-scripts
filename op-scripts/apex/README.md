------------------------------------
        VARIANTS
------------------------------------

> Apex-main.py -> deals with full json export from caido

> Apex-singular.py -> deals with findings json export from caido


------------------------------------
        Purpose
------------------------------------

> parse entire http json file exported to find specified keywords
in various contexts and return it with a word radius specified in the
search config file.


---------------------------------------
        Features
---------------------------------------

> returns word radius text extracts of the keywords with the following attributes:

- hostname
- api path
- http method
- keyword

----------------------------------------
        Instructions
----------------------------------------

> Place your json file in the json-file directory
> Configure the search parameters in the search_config/search.json file.
> Do your stuff
